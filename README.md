# DigiTools Platform 🛠️

**Live Demo:** [Visit Live Site](https://digitools-platform-masrafi.netlify.app/)

## 📖 Description
DigiTools Platform is a fully responsive frontend web application for browsing and purchasing digital products and software tools. The platform features an interactive user interface where users can seamlessly toggle between product listings and their shopping cart, complete with real-time feedback and dynamic state management. 

## ⚙️ Technologies Used
* **React.js** - UI Library
* **Tailwind CSS & DaisyUI** - Styling and Component framework
* **JavaScript (ES6+)** - Core logic
* **React-Toastify** - Notification and alert system
* **JSON** - Mock database for fetching product information

## ✨ Key Features
1. **Dynamic Section Toggling:** Users can easily switch between the main "Products" view and the "Cart" view using central toggle buttons, providing a seamless single-page application experience.
2. **Interactive Cart Management:** Features a fully functional cart system where users can add items, remove specific selections, view total counts dynamically in the navbar, and clear everything via a "Proceed to checkout" action. 
3. **Real-Time User Notifications:** Integrated with React-Toastify to display beautiful, instant alerts whenever a user interacts with the cart (adding products, removing products, or checking out).
